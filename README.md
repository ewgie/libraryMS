# libraryMS
This is a simple Library Management System built in Python. The system allows users to register books and students, borrow and return books, delete records, list available books and students, and check book or student statuses. Data is stored in text files, and users interact through a menu-based interface.

Key features:

Register books and students
Borrow & Receive books with validation
Delete book or student records
List books, borrowed books, and student histories
Check book availability and student loans
Quit the system when done
